# Créditos de las fotos de las tiendas de ejemplo

Fotos de los productos de las demos (Tienda Lumbre, Café Bruma, Almacén Verde y las tiendas de ejemplo
de cada plantilla) que reemplazan a las que no mostraban el producto. Todas son de uso libre, también
comercial: CC0 o dominio público (StockSnap, rawpixel, Wikimedia Commons, Flickr vía Openverse) o la
licencia de Unsplash. Se sirven desde acá, recortadas a 1200 px y en webp; el catálogo las usa con la
URL completa `https://tulocalweb.com.ar/demo/<tienda>/<producto>.webp`.
